# OGLY Whitepaper

## Vision

A token whose supply reflects the results of a real trading operation, in plain view and on a public chain.

## Mission

Turn realized fund gains into open-market demand for OGLY, and remove every token bought that way from circulation for good. Publish each step so anyone can check it.

## How it works

1. The fund trades and realizes gains.
2. Fifty percent of the available realized gains is earmarked for OGLY purchases.
3. The earmarked amount buys OGLY on public markets.
4. Every token bought through the earmarked amount is burned.

The other fifty percent stays outside the program. A burn reduces supply; it does not set a price level or promise an outcome.

## Roadmap

### Phase 1: Launch

Publish the mint, open the public channels, and bring the live board online.

### Phase 2: First buy and burn

Run the first purchase from the earmarked share, burn every token acquired, and publish the transaction records.

### Phase 3: Widen the base

Grow the fund's capital and the venues it can reach once the full loop has run.

### Phase 4: Refine

Improve research, execution and reporting for the fund.

Phases are goals in order, not promised delivery dates.
